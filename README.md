# Mungos — веб-сервис для анализа сетевого трафика

Mungos — автоматизированная система мониторинга и классификации сетевого трафика с поддержкой методов SNI и JA4+.



## Реализованные возможности

- Горизонтальное масштабирование анализаторов трафика
- Сокрытие персональных данных (IP, MAC)
- Собственная библиотека ja4go для отпечатков JA4, JA4S, JA4T, JA4H (HTTP/1.1)
- Синхронизация классификационных баз SNI и JA4+ между снифферами
- BPF-фильтры для отсева служебного трафика на уровне ядра
- Кеш-фильтрация по правилам для уже известных соединений
- Поточный анализ пакетов из сниффера с просмотром деталей
- Реализована система анализа пакета для ручной идентификации всего соединения
- Предустановленный дашборд Grafana для выявления аномалий
- Единый файл переменных окружения для всех настроек
- Отдельный docker-compose для запуска сниффера в режиме хоста
- Полный цикл сборки, установки и настройки всех модулей в docker-compose

| Сниффер | Go 1.24, gopacket, gRPC, ClickHouse |

## Системные требования

- Docker 20.10+
- CPU: 4 ядра
- RAM: 16 ГБ
- ОС: Linux (Ubuntu 20.04+, Debian 11+)

Система протестирована на указанной конфигурации. Результаты: пиковая нагрузка 127 252 пак./с, автоматическая идентификация 89,32% пакетов.

## Безопасность

- JWT-аутентификация с токенами
- Хеширование паролей BCrypt
- Ролевая модель доступа (ADMIN, ANALYTIC, SECURITY)
- Обезличивание IP-адресов (замена последнего октета на \*\*\*)
- Обезличивание MAC-адресов (отображение только первых трех байт)
- gRPC-взаимодействие между модулями с TLS-шифрованием
- Мастер-ключ для регистрации снифферов с последующей выдачей ключа сессии
- Политика "одного клиента" — только один Core может зарегистрироваться и получить сессионный ключ
- Требование смены пароля при первом входе
- Полное проксирование Grafana и Prometheus через Core — прямой доступ к сервисам мониторинга извне отсутствует

## Структура проекта
```text
Mungos/
├── sniffer/ # Модуль захвата и классификации трафика (Go)
├── core/ # Бэкенд-ядро (Java/Spring Boot)
├── frontend/ # Веб-интерфейс (Angular)
└── deploy/ # Оркестрация и конфигурация (Docker Compose)
```

> [!NOTE]
>
> ### Ограничения классификации
> Библиотека ja4go реализует только отпечатки JA4, JA4S, JA4T и JA4H (HTTP/1.1).
> JA4X, JA4L, JA4SSH, JA4DHCP и JA4H для HTTP/2 не поддерживаются.


> [!IMPORTANT]
>
> ### BPF-фильтры по умолчанию
> Служебный мультикаст, броадкаст и DNS трафик исключены из захвата фильтром по умолчанию:
>
> `not ip multicast and not ip broadcast and not (src port 53 or dst port 53)`

> [!WARNING]
>
> ### Настройка перед стартом
> Перед запуском проекта в рабочей среде обязательно измените следующие переменные в файле `deploy/.env`:
> - `DB_PASS` — пароль PostgreSQL
> - `SNIFFER_DB_PASS` — пароль ClickHouse
> - `ADMIN_PASSWORD` — пароль администратора
> - `JWT_SECRET` — секретный ключ для JWT
> - `DEFAULT_MASTER_KEY` — мастер-ключ для регистрации снифферов
> - `SNIFFER_FILTERS` — BPF-фильтр под вашу сеть
> - `GRAFANA_ADMIN_PASSWORD` — пароль Grafana

## Быстрый старт

### Клонирование репозитория

```bash
git clone https://github.com/JavaBruse/Mungos.git
cd Mungos
```
### Запуск основного модуля (Core + Frontend + PostgreSQL + Prometheus + Grafana)

```bash
docker-compose -f deploy/docker-compose.master.yml up -d --build
```

### Запуск сниффера (Sniffer + ClickHouse)
```bash
docker-compose -f deploy/docker-compose.sniffer.yml up -d --build
```


### Запуск сниффера в режиме host (Sniffer + ClickHouse):
```bash
docker-compose -f deploy/docker-compose.sniffer-host.yml up -d --build
```

### Доступ к веб-интерфейсу
```text
http://localhost
```
